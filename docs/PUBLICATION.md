# Publication scope

The owner authorized publication of this clean source repository on 2026-10-10.
Only main is published. Historical local development commits and private inputs
are retained locally and in the complete pre-publication archive; they are not
ancestors of public main. No Tag, binary ZIP upload or hosted Release is created.

Existing LICENSE.md and third-party notices retain their component-specific
scope. No additional license has been selected for newly authored integration;
public visibility alone does not grant reuse rights in that material.

Before any public binary distribution:

- Resolve rights to distribute compiled cartridge and retail BIOS translations.
  Excluding raw inputs does not establish derivative distribution permission.
- Confirm dependency conditions, including PolyForm Noncommercial, inherited
  integration terms, font attribution/share-alike, and exact GCC/MinGW library
  corresponding-source availability.
- Complete owner acceptance of the final launcher package.

Full stage completion and later-game compatibility remain unverified. The source
build uses fixed dependency snapshots and the user's own validated ROM/BIOS.
No legal clearance for binary publication is claimed.
